🛡️ Security Information and Event Management (SIEM) System
A simplified SIEM solution that collects, monitors, and analyzes security-related data from network systems to detect suspicious activity and support cybersecurity investigations.

🔧 Tech Stack
Backend: Python (Flask or FastAPI)

Frontend: HTML, CSS, JavaScript (optional for dashboard)

Database: SQLite / MongoDB / PostgreSQL

Log Collection: Syslog / Custom Log Parser

Visualization: Matplotlib / Chart.js / Plotly (optional)

🧰 Key Features
📥 Log Collection: Collects logs from multiple sources (servers, apps)

📊 Event Dashboard: View logs in a structured format

🚨 Alert System: Detects suspicious activity (e.g., failed logins, IP scanning)

📁 Log Storage: Store and retrieve logs for audit trails

🧠 Rule-Based Detection: Apply predefined rules to flag anomalies

📅 Timestamping: All logs are time-tracked for forensics
